A framework-free, typed filter bar for your data.

In your application

1. Load assets

<link rel="stylesheet" href="./dist/styles.css">
<div id="filters"></div>
<script type="module" src="./filters.js"></script>

2. Define fields

import { Siftbar } from './dist/siftbar.js';

const bar = new Siftbar(host, {
  fields,
  onChange: updateResults,
});

3. Connect results

Implement updateResults to fetch and render your data. The working handlers are shown below.
